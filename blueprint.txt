1. Executive Summary
   — What SmartVault is
SmartVault is a local-network, browser-based document and file management system for offices managing large volumes of documents across multiple companies, departments, and financial years. It runs entirely on your own dedicated server — no cloud, no Docker, no external dependencies — giving you complete data privacy and control.

9. Disaster Recovery Plan
   — Three-tier · RTO under 4 hours
Disaster recovery means: if something goes wrong — accidental file deletion, database corruption, hard drive failure, power surge, fire, theft — how quickly can SmartVault be restored? This plan gives three tiers of protection.
9.1 Tier 1 — Live server (zero recovery time)
This is the running system. No recovery needed if the server is healthy. Protection at this tier comes from the OS and file system reliability:
M.2 NVMe SSD for OS and databases — much more reliable than HDDs for read/write operations
PostgreSQL write-ahead logging — database is crash-safe; no data loss even if power cuts mid-write
MinIO file storage with checksums — detects and alerts on file corruption automatically
UPS (uninterruptible power supply) — gives the server time to shut down cleanly during a power cut
9.2 Tier 2 — Dedicated backup HDD (recovery in 2–30 minutes)
A dedicated backup hard drive at /mnt/backup/ — a separate physical drive used for nothing else. Automated scripts run every night at 2 AM.

A mathematical fingerprint of a file's content. Identical content = identical fingerprint. Used for duplicate detection.
rsync
A backup tool that copies only files that have changed — fast and efficient for large file collections.
pg_dump / pg_restore
PostgreSQL's built-in backup and restore commands. Create a complete snapshot of the database.
Service Worker
A browser technology that caches content for offline use. Enables the offline read-only mode. Nothing to install.
ZPL
Zebra Programming Language — the file format used to send label designs to Zebra thermal printers.
JWT
A secure digital token — proves who you are when making requests to SmartVault. Expires automatically.
API key
A password that connects SmartVault to an AI service. Without it, all AI features stay disabled.
FY (Financial Year)
April 1 to March 31. SmartVault organises all files within FY folders. Current FY is the default view.
Audit log
A permanent record of every action — who did what, to which file, when, from which IP address.
Rollback
Reversing a logged action — returning a file, folder, or permission to exactly how it was before.
Retention policy
A rule that says how long a file must be kept before it can be considered for deletion or archiving.
UPS
Uninterruptible Power Supply — a battery backup that gives the server time to shut down safely during a power cut.
