# SmartVault

SmartVault is a document and media vault application with a Next.js frontend and a Node.js API backend.

**Deployment docs**

| File | Use when |
|------|-----------|
| **`DEPLOYMENT_TEACHING_GUIDE.md`** | Main **walkthrough**: what each step does, **when / when not**, **`npm install` vs `npm run build`**, full DB SQL + admin script, PM2/nginx checklist. |
| **`BAREMETAL_DEPLOY.md`** | **Quick map**: hardware paths, `.env` example, symlink note for two media HDDs. |
| **`DEPLOYMENT_GUIDE.md`** | Extra **troubleshooting** and duplicate procedures if something fails. |

Recommended order: **`DEPLOYMENT_TEACHING_GUIDE.md`** → keep **`BAREMETAL_DEPLOY.md`** nearby → **`DEPLOYMENT_GUIDE.md`** only if stuck.
